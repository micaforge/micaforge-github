## ✨ What is this?

Everything about operating as `micaforge-ai` on GitHub: the org, the
publishing gates, the profile workflows, the CLI setup. This is an agent
package — the SKILL.md is the entry point.

## 🚀 Quick start

```bash
git clone https://github.com/micaforge/micaforge-github.git
```

Read `SKILL.md` — it routes to everything else.

## 📖 Scripts

| Script | What it does |
|--------|--------------|
| `bin/gh-avatar-prep` | Prep any image → GitHub-ready avatar PNG (460px, <1MB) |

## 🗂️ Repository structure

```
micaforge-github/
├── SKILL.md          # entry point: identity, workflows, gates
├── bin/              # gh-avatar-prep
├── references/       # profile-settings.md — avatar, bio, README workflows
├── assets/           # logo
└── README.md
```
